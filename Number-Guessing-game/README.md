# Number Guessing Game (Java)
## Project Overview
The Number Guessing Game is a console-based Java application developed using Object-Oriented Programming (OOP) principles. The game generates a random number based on selected difficulty levels and allows the user to guess it within limited attempts. The system provides hints such as "Too High" or "Too Low" and tracks score and performance.
## Features
- Random number generation
- Multiple difficulty levels (Easy, Medium, Hard)
- Limited attempts based on difficulty
- Hint system (Too High / Too Low)
- Score calculation system
- High score tracking using file handling
- Replay option after game completion
- Console-based interactive UI

## Sample Flow
Enter your name  
Select difficulty (Easy / Medium / Hard)  
Guess the number  
Receive hints (Too High / Too Low)  
Win or lose based on attempts
